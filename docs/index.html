安装

macOS 13+（Apple Silicon）或 Windows 10 19041+ / Windows 11（x64）。

🍎 macOS

$ brew tap ekreke/tokcat https://github.com/ekreke/TokCat
$ brew trust ekreke/tokcat
$ brew install --cask tokcat

第三方 tap 需先 brew trust。安装后在「启动台 / 应用程序」或 Spotlight 打开（菜单栏应用，运行时不显示 Dock 图标）。App 为 ad-hoc 签名（未公证），被拦时右键「打开」，或到「系统设置 → 隐私与安全性 → 仍要打开」。

🪟 Windows

  1. 下载 TokCat.exe（单文件，免安装）
  2. 双击运行；若 SmartScreen 提示，点「更多信息 → 仍要运行」
  3. 托盘出现小猫，随 token 速率奔跑
⬇ 下载 Windows 版（.exe）

左键看状态，右键菜单切换速率口径 / 尺寸 / 数据源 / 开机自启。opencode 采集支持原生 Windows。

接入 Hermes

ACP Client 目前只接 Hermes，本地或远程 SSH 都行。

💻 本机

  1. 右键猫图标 →「Hermes → 设置…」
  2. 点「一键安装」执行官方脚本
  3. 点「登录」跑 hermes acp --setup

🛰️ 远程 SSH

  1. 填 SSH 目标（别名或 user@host）
  2. 必要时填私钥、登录 shell 包装
  3. 点「测试连接」验证后保存
